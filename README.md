# 🛕 Sri Venkateshwara Swamy Temple — Polireddypalem

Official website for **Sri Venkateshwara Swamy Temple, Polireddypalem**, created to preserve the temple's history, share construction progress, provide donation information, and connect devotees with the temple community.

## 🌐 Website

The website provides information about:

- 🛕 Temple history and heritage
- 🏗️ New temple construction journey
- 🙏 Devotee and donor information
- 💰 Official donation and bank details
- 🖼️ Temple gallery
- 📍 Temple location and Google Maps
- 📞 Contact information
- 🎉 Festivals and traditions
- 🌐 English and Telugu language support

---

## ✨ Features

### 🌐 Bilingual Website

The website supports:

- 🇬🇧 English
- 🇮🇳 Telugu (తెలుగు)

Visitors can switch between English and Telugu throughout the website.

---

### 🛕 Temple History

The history section documents the heritage of the original temple.

The original temple was built in the **1960s by Late Thambireddy Ramana Reddy from Chennai** and served the village community and devotees for several decades.

The website also presents historical photographs and information about the temple's heritage.

---

### 🏗️ Construction Journey

The new temple construction is presented as a chronological journey.

Current stages include:

1. Old Temple
2. New Temple Foundation Ceremony
3. Basement Construction
4. Garbhalayam Construction
5. Roof Construction
6. Gopuram Construction
7. Upcoming Stages

Each stage can include:

- Construction date
- Description
- Photograph
- Construction status

---

### 🙏 Donors

The website includes an official donor section containing selected donor records.

The donor list includes:

- Donor Name
- Donation Date
- Donation Amount / Material

Duplicate donor records are consolidated according to the temple donation records.

---

### 💰 Donations

The donation section provides official bank transfer information supplied by the temple committee.

Information includes:

- Bank Name
- Account Holder Name
- Account Number
- IFSC Code
- Branch
- UPI ID
- Donation QR Code

> ⚠️ Donors should verify the bank details with the temple committee before making a donation.

---

### 🖼️ Gallery

The gallery is organized into categories:

- Old Temple
- Latest Updates
- Festivals
- Temple Events

The gallery is designed to allow the temple committee to add new photographs as construction and events progress.

---

### 📍 Temple Location

The website includes:

- Temple address
- Google Maps location
- Google Maps directions
- Embedded map
